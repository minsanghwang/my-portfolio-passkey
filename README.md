# 포트폴리오 + 패스키로 잠근 나만의 자리 (8번 과제)

1번 과제의 공개 소개 페이지는 그대로 두고, 맨 아래에 **패스키로 잠근 비공개 자리**를 붙였습니다.
비밀번호는 만들지 않습니다.

- 첫 화면: 누구나 볼 수 있는 소개 페이지 (PUBLIC)
- 맨 아래 `나만의 자리` (PRIVATE): 패스키로 들어가야만 내용이 내려옵니다

> 이 저장소와 화면의 비공개 항목은 모두 **데모용으로 만들어 넣은 내용**이며 실제 개인정보가 아닙니다.

## 구조

| 위치 | 역할 |
| --- | --- |
| `index.html`, `css/`, `js/main.js`, `js/contact.js` | 1번 과제의 공개 소개 페이지 (내용 그대로) |
| `js/auth.js` | 브라우저 쪽: 서버가 준 질문에 기기가 서명하도록 요청하고, 공개키·서명만 서버로 보냄 |
| `supabase/functions/passkey-api/index.ts` | 서버: 등록·로그인·로그아웃·비공개 자료 조회, 패스키 목록·추가·삭제 |
| `supabase/migrations/001_init.sql` | 표 정의. 비밀번호 칼럼 없음, 공개키만 저장 |
| `vercel.json` | `/api/*`를 서버 함수로 이어 주고(같은 출처), 보안 헤더 설정 |
